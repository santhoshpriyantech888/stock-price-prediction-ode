# 📈 Stock Price Prediction using ODE

## 📌 Overview
This project predicts stock prices using Ordinary Differential Equations (ODE) based on continuous growth models.

## 🎯 Objective
To model stock price behavior using mathematical equations and numerical methods.

## 🛠️ Technologies Used
- Python
- NumPy
- Matplotlib
- yFinance

## ⚙️ Features
- Fetch real stock data
- Estimate growth rate
- Predict future prices
- Graph visualization

## 🧩 How It Works
- Uses equation: dS/dt = μS
- Estimates μ from historical data
- Applies Euler method for prediction

## ▶️ How to Run
pip install -r requirements.txt  
python main.py
